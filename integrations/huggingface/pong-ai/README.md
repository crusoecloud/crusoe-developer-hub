# Pong AI

**Two LLMs compete in Pong, powered by [Crusoe Intelligence Foundry](https://www.crusoe.ai/cloud/managed-inference).**

## How It Works

1. Enter your Crusoe Foundry API key
2. Pick two models to battle
3. Click **Start Battle!** and watch them play

## Models Available

- DeepSeek-V3-0324
- DeepSeek-R1-0528
- Llama 3.3 70B Instruct
- Qwen3 235B A22B Instruct
- Gemma 3 12B

## Built With

- **Frontend**: Gradio + HTML5 Canvas
- **LLM API**: Crusoe Intelligence Foundry (OpenAI-compatible)
- **Deployment**: Hugging Face Spaces
