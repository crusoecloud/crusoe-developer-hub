# Cookbooks

**Planned content. No standalone cookbooks are published here yet.**

Cookbooks are short, focused recipes with a concrete result and a small number of steps. Longer task workflows belong in infrastructure, training, or inference; guided event sessions belong in workshop.

The existing recipes below focus on connecting a named tool, so their implementations live in Integrations:

| <div align="center">Recipe</div> | <div align="center">Primary home</div> |
| --- | --- |
| Add web search to a tool-calling loop | [Tavily](../../integrations/tavily/) |
| Add search and sourced answers to a model workflow | [Linkup](../../integrations/linkup/) |
| Make requests through a gateway | [LiteLLM request examples](../../integrations/litellm/#clients) |

Each recipe has its own dependencies and credentials. API calls and third-party services can incur charges. Link to these implementations rather than copying them into this section.
