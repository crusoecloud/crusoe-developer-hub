# The Recursive Agents Hackathon 2026

[The Recursive Agents Hackathon](https://cerebralvalley.ai/e/crusoe-recursive-agents-hackathon) ran on October 17, 2026 in San Francisco during the PyTorch Conference, hosted by [Cerebral Valley](https://cerebralvalley.ai/) and Crusoe, with $25,000 in cash prizes and an NVIDIA RTX 5090. The brief was to build a team of agents you can walk away from, on [Crusoe Managed Inference](https://www.crusoe.ai/cloud/managed-inference) with open models including NVIDIA's Nemotron family. The event kit, including the Crusoe skill file participants used, is in the [developer hub](https://github.com/crusoecloud/crusoe-developer-hub/tree/main/examples/hackathons/crusoe-cv-recursive-agents-hackathon).

The [gallery](https://cerebralvalley.ai/e/crusoe-recursive-agents-hackathon/hackathon/gallery) holds 90 submitted projects. Because the event ran on Crusoe Managed Inference, every entry is listed here. The Crusoe usage column quotes the project's gallery description or its README where either names Crusoe; where neither does, it notes the event platform.
