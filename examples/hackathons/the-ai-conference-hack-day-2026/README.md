# The AI Conference Hack Day 2026

[The AI Conference Hack Day 2026](https://hackersquad.io/events/the-ai-conference-hack-day-2026), organized by [HackerSquad](https://hackersquad.io/) alongside The AI Conference and sponsored by Crusoe, on Tuesday, September 29, 2026 at Pier 48 in San Francisco.

The event ran on [Crusoe Managed Inference](https://www.crusoe.ai/cloud/managed-inference), which serves open models, behind one OpenAI-compatible endpoint. Crusoe funded the overall cash prize pool, and projects had to use Crusoe to qualify for it.

## Getting started

Follow the steps below to get started on Crusoe Managed Inference

1. Sign up for an account here: https://console.crusoecloud.com/request-foundry
    > We recommend one teammate creates the Crusoe organization, then invites the rest of the team into it so everyone can generate their own API token under the same org. Sharing a single token across the team also works fine if you'd rather keep it simple, just make sure whoever holds it doesn't leave before the hackathon ends. **You will need to add a valid credit card to get your free credits.**
2. Click **Get API Key** on the top nav bar to generate a key.
    - Give it an alias, and set the expiration date to the hackathon end date; this caps your blast radius if the key ever leaks, and avoids surprise charges after the event.
    - Click **Create** and save the key somewhere safe, it's only shown once.
3. Send your first chat request using the sample code in the UI, or give the [Crusoe skill file](../crusoe-cv-recursive-agents-hackathon/crusoe-cv-recursive-agents-hackathon-skill.md) to your coding agent and ask it to start building.

_If you run into any issues, contact a Crusoe team-member in-person at the venue or on Discord._
