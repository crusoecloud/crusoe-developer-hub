# Skills

Skills are packaged instructions and scripts that a coding assistant such as Claude Code loads when a task calls for them. The examples here keep the assistant as the conversation and run the model work on Crusoe Managed Inference.

| <div align="center">Skill</div> | <div align="center">Outcome</div> | <div align="center">Requirements</div> |
| --- | --- | --- |
| [eBay Fashion Tracker](ebay-fashion-tracker/) | Describe a fashion item with a photo, a link or a sentence; open models on Crusoe build a typed spec and judge new eBay listings against it; a background poller alerts you on Slack or your phone with price and bid state | Python 3.9+, Claude Code, a Crusoe API key, an eBay developer keyset, and Slack or Pushover |
