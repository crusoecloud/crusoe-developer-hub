# Workshops

Guided, end-to-end sessions delivered at conferences, community events and internal enablement. Each workshop connects several tasks into one coherent learning experience with clear checkpoints, states its prerequisites and duration, and is reusable outside the event it was first run at.

| <div align="center">Workshop</div> | <div align="center">Duration</div> | <div align="center">You will</div> | <div align="center">Requirements</div> |
| --- | :---: | --- | --- |
| [Serve, Measure, Tune: SGLang on Crusoe Managed Kubernetes](sglang-kubernetes-workshop/) | 90 min session (about 60 min hands-on) | Deploy SGLang on Kubernetes with KServe, benchmark it under realistic load, and tune KV cache precision and scheduling on your own GPU. | A Crusoe Managed Kubernetes cluster with GPU node pools and KServe (provided in facilitated sessions), `kubectl`, `uv` |

Start with the workshop's README: it lists what to install before the session and how the parts fit together. Workshops incur GPU charges while their deployments exist; every one ends with a cleanup section.

For shorter material, browse [Foundations](../../foundations/), the [training examples](../training/), or [Integrations](../../integrations/).
