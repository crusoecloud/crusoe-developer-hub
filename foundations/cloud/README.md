# Cloud Foundations

**Planned content.** This track currently contains a scope description only. There are no lessons or runnable exercises yet.

Learn the infrastructure concepts behind running AI workloads in the cloud. Proposed topics include:

- **Storage:** block, object, and shared file storage; persistence, access patterns, data movement, and choosing storage for a workload.
- **Customer-managed keys (CMK):** encryption key ownership, access control, rotation, and the effect of key availability on access to encrypted data. In this track, CMK means customer-managed keys, not Crusoe Managed Kubernetes.
- **Slurm:** jobs, queues, partitions, resource requests, scheduling, and the relationship between a scheduler and a compute cluster.
- **Related concepts:** virtual machines, networking, identity, and the resource lifecycle.

These are proposed teaching topics, not a list of supported Crusoe product features.

Use [infrastructure examples](../../examples/infrastructure/) for task-oriented setup and provisioning content. Small exercises that help explain a concept can live here; complete deployment recipes belong in examples.
