# Tiles

These 96 × 96 PNG tiles are the small images used inline in the hub README: four link-row tiles and eight model-provider marks. Each is a black square with either a glyph from the brand kit's icon library in Hi-Vis Yellow, recolored only by swapping the glyph's single fill value, or a third-party mark in white. They match the banner's black background and Hi-Vis Yellow linework. They are generated by [../generate-artwork.py](../generate-artwork.py); do not edit them by hand. Tiles that drop out of the generator's tables are deleted on the next run.

## Link-row tiles

## Third-party marks

`logo-*.png` tiles place a model provider's mark on a black square so it reads the same in both GitHub themes. Monochrome SVG marks are rendered in white; raster marks keep their own colors. They appear at 28 px in the models table of the hub README. Originals and sources are documented in [../third-party/README.md](../third-party/README.md).
